# 日語假名學習工具

一個專為繁體中文使用者設計的日語假名學習網頁應用程式，支援平假名和片假名的互動式學習。

## 功能特色

### 📚 字母表檢視
- 完整的平假名和片假名字母表
- 包含清音、濁音、半濁音和拗音
- 點擊字符可查看羅馬字讀音
- 使用瀏覽器的語音合成 API 播放日語發音（如果可用）
- 可依類型篩選顯示

### 🧠 測驗模式
- **假名 → 羅馬字**：看假名選擇正確的羅馬字
- **羅馬字 → 假名**：看羅馬字選擇正確的假名
- 可自選練習的行段（あ行、か行等）
- 支援「弱項練習」模式，自動練習正確率低於 70% 的字符
- 即時回饋和計分

### 📊 進度追蹤
- 使用 localStorage 儲存學習進度
- 追蹤每個字符的正確率
- 視覺化顯示各字符的表現
- 自動標記弱項字符供重點練習

### 📱 響應式設計
- 完全支援手機和桌面瀏覽器
- 優化觸控操作體驗
- 深色模式支援

## 技術架構

- **框架**: React 19 + TypeScript
- **建置工具**: Vite 8
- **樣式**: Tailwind CSS 4
- **圖示**: Lucide React
- **語音**: Web Speech API

## 本地開發

### 環境需求

- Node.js 18 或更新版本
- npm 或 yarn

### 安裝步驟

1. 安裝依賴套件：

```bash
npm install
```

2. 啟動開發伺服器：

```bash
npm run dev
```

3. 在瀏覽器中開啟顯示的本地網址（通常是 `http://localhost:5173`）

### 建置生產版本

```bash
npm run build
```

建置完成的檔案會輸出到 `dist` 目錄，可直接部署到任何靜態網站託管服務。

### 預覽生產版本

```bash
npm run preview
```

## 使用說明

1. **選擇假名類型**：在頂部選擇「平假名」或「片假名」
2. **字母表模式**：
   - 瀏覽所有字符
   - 點擊任何字符查看讀音並聽發音
   - 使用篩選按鈕只顯示特定類型
3. **測驗模式**：
   - 選擇測驗方向和練習範圍
   - 勾選要練習的行段
   - 開始測驗並選擇正確答案
   - 查看即時回饋和最終成績
4. **進度追蹤**：
   - 查看整體統計數據
   - 檢視各字符的詳細表現
   - 識別需要加強的弱項
